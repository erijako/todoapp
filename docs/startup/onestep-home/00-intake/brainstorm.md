# Brainstorm: Onestep Home

**Phase:** 2 Brainstorm
**Project:** onestep-home
**Date:** 2026-11-25
**Confidence:** Low (ikke testet mot kunder ennå)

---

## Variantene som ble vurdert

| | Variant | Spennende | Risikabelt |
|---|---|---|---|
| A | Alt i ett: meg + oss to + kollektiv, full Home | Én app, tre scenarioer | Mest arbeid; kopi av Flatastic i kollektiv |
| B | **Din del havner på låseskjermen** | Eneste reelle differensiering; bygger på kjernepitchen | Én plass på låseskjermen: hva vinner? |
| C | Handleliste først | Lite arbeid, høy frekvens | Apple Påminnelser har delte lister gratis |
| D | Bare én trenger appen (SMS/nettlenke til resten) | Løser installasjons- og Android-problemet | Krever egen server |
| E | **Rettferdig uten mas** (bytt tur, takk, ingen poengtavle) | Følelsesmessig posisjonering; passer verdiene | Rotasjon krever at noen ser om det ble gjort |
| F | **Kjærester først, kollektiv senere** | Lett å teste, færre må installere | Mindre kaos å løse |
| G | Distribusjon via studentboliger (SiO o.l.) | Mange kollektiv på én gang; norsk fordel | B2B-salg tar tid; Android blir krav |

## Valgt retning (founder: "ja", 2026-11-25)

1. **Felles vaskeliste (med rotasjon) og handleliste** for kollektivet.
2. **Din del havner på låseskjermen** som ditt neste steg; huk av uten å låse opp (B).
3. **Uten mas**: ingen poengtavle, ingen skam, bytt tur (E).
4. **Kjærester først, så kollektiv** (F).

Arbeidshypotese for posisjonering: *"Den eneste husholdningsappen som legger din del på
låseskjermen, uten mas og uten poengtavle."* [Mening]

Parkert: D og G (til research viser om iPhone-kravet dreper kollektiv-ideen).

---

## Flags

**Red Flags:**
- None identified

**Yellow Flags:**
- Apple Påminnelser (delte lister) er gratis substitutt for par og handleliste.
- Konflikt mellom kollektivets oppgave og din egen viktigste ting på én widget-plass er uløst.
- Rotasjon vs. "ingen overvåking"-verdien må løses i design.
