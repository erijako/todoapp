# Lean Canvas

**Phase:** 4 Strategy
**Project:** onestep-home
**Date:** 2026-11-25
**Confidence:** Low (ingen kundeintervjuer, utsatt av founder)

---

| Blokk | Innhold |
|---|---|
| **Problem** | 1) Ting glemmes når de ikke er foran øynene ("ute av syne, ute av sinn"). 2) Én person i paret bærer husets mentale last. 3) Kollektiv: uklart hvem sin tur det er, tomt for felles varer, irritasjon. |
| **Kundesegmenter** | Beachhead: **samboerpar 22–32 der begge har iPhone** (Norge). Deretter: kollektiv (krever Android). Personlig bruk: alle med "mange baller i lufta". |
| **Unik verdi** | *"Din neste ting, og din del av hjemmet, rett på låseskjermen. Uten mas."* |
| **Løsning** | Lock screen-widget med ett neste steg; Home: felles liste/handleliste, din del havner som ditt neste steg; milde påminnelser; ingen poengtavle. |
| **Kanaler** | TikTok/Instagram på norsk (mental load, kollektivkaos), App Store-søk på norsk, venner/TestFlight, invitasjonslenken selv (hver Home-invitasjon er en ny bruker). |
| **Inntekter** | Freemium: Home gratis; Pro ($4.99/mnd, $34.99/år, $79.99 livstid) for personlige superkrefter. |
| **Kostnader** | Apple Developer $99/år; founders tid; ingen server så lenge iCloud brukes. |
| **Nøkkeltall** | Ukentlig aktive Homes (2+ medlemmer som krysser av), andel som legger til widgeten, gratis→Pro-konvertering. |
| **Urettferdig fordel** | Svak: produktet er bygget rundt én neste ting på låseskjermen (vanskelig for dashbord-apper å kopiere raskt) + norsk språk og tone. Ingen reell vollgrav. [Opinion] |

---

## Flags

**Red Flags:**
- Kollektiv krever Android/egen backend; iCloud-versjonen når få kollektiv (se `01-discovery/market-analysis.md`).

**Yellow Flags:**
- Bygger på antakelser; intervjuer utsatt.
- Pro er tynt (bare fokus-timer) for å bære inntekten.
